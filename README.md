# tyrepartners-doorsturen

Stuurt het kale domein tyrepartners.com door naar https://www.tyrepartners.com, met behoud van pad en query
(SHD Services, 16 oktober 2026). De DNS van tyrepartners.com ligt bij Itum (ns1.odrdns.eu): de vier A-records
van GitHub Pages wijzen hierheen, www is een CNAME naar Cloudflare Pages (project tyrepartners).
404.html is gelijk aan index.html, zodat elk pad doorstuurt. Niet verwijderen zolang de A-records naar GitHub
Pages wijzen: anders kan iemand anders het domein hier claimen.
